## 目前主要專案

### LINE 自動找房〔規劃中〕
目標流程：客戶於 LINE 官方帳號輸入區域及條件 → n8n 整理條件 → 查詢房源資料庫 → 回傳符合條件的房源。

- 規劃需涵蓋房源上下架、更新日期、條件篩選、持續運作與備份。
- LINE 串接完成狀態、房源資料來源與格式尚未確認。
- 資料庫尚未確認選定或完成建置；Baserow 是討論過的選項，不代表已採用。
- 跨 AI 自動同步也尚未確認完成。

### 房源影音與中文口播〔持續實作〕
結合房屋照片、現有影片、中文配音、字幕及人像動畫，製作可匯入 CapCut 後製的房源介紹內容。只使用真實提供的房源資訊，不生成或暗示不存在的房屋特色。
