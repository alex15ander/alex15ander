  - 嚴格避開法律紅線、資金安全陷阱與無意義的精力浪費。
- **記憶與偏好更新規則**：
  - 每次任務對話後，由 AI 自動辨識長期有效的新增偏好。

## 工作領域與用途

依對話可確認：工作涉及房源介紹、房仲行銷、找房條件篩選與客戶服務。

常見產出：繁體中文房源文案、中文配音、字幕、直式房源影片與人像口播。

不得自行編造價格、坪數、地點、房屋特色或未提供的交易資訊。

## 目前主要專案

### LINE 自動找房

希望讓客戶在 LINE 官方帳號輸入區域及條件，經由 n8n 查詢房源資料庫後回傳房源。

- n8n 已安裝在使用者的 Mac。
- LINE 是否已串接 n8n：尚未確認。
- 房源資料來源與格式：尚未確認。
- 資料庫：尚未選定或完成安裝。Baserow 是討論過的選項，不應視為已採用。
- 系統須考慮房源上下架、更新日期、實際篩選條件與持續在線需求。

### 影音與人像生成

- 已決定使用 CapCut 進行影片剪輯，Shotcut 已由使用者移除。
- 使用 VoiceStudio 製作自己的中文聲音；仍重視咬字與發音品質。
- 已測試 Open Generative AI 的 Z-Image Turbo 本機圖片生成。
- 已安裝 HyperFrames、Blender、ComfyUI、AnimateDiff 與黏土風格 LoRA。
- LivePortrait 已安裝並用範例驗證人像動畫；使用照片與驅動影片，不應描述為原生音訊對嘴工具。
- 使用者希望用自己的照片與中文配音製作口播影片。

## 執行環境

- Apple Silicon Mac，已確認記憶體為 16 GB。
- 時區：Asia/Taipei。
- 影片生成需考量記憶體與處理速度，先用短片和小尺寸驗證。
- 上述安裝狀態可能隨使用者操作而改變，實際使用前應確認。
